## 🚀 Cara Pakai

1. Pilih mod atau file terjemahan yang tersedia.
2. Ikuti instruksi penggunaan di masing-masing folder atau dokumentasi.
3. Gunakan dengan bijak dan sesuai lisensi yang berlaku.

## 🤝 Kontribusi

Kontribusi sangat terbuka untuk siapa saja.

- Laporkan bug atau masalah
- Ajukan terjemahan baru
- Perbaiki kata/kalimat yang kurang natural
- bantu update daftar game dan dokumentasi

## ⚠️ Catatan

Repo ini dibuat untuk kebutuhan komunitas dan penggunaan secara gratis. Mohon jangan diperjualbelikan atau dipakai untuk menutup akses secara berbayar.

## 📜 Lisensi

Gunakan sesuai ketentuan yang berlaku di repo ini. Jika ada lisensi spesifik untuk file tertentu, silakan periksa tiap folder/file terkait.
